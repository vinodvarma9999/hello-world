          Backup & restore

          Your expenses are stored only on this phone. Deleting the app from your home screen deletes them too, so keep a backup in Files or iCloud Drive.

          Bank statement

          Add past expenses (for example from 1 August) from your bank statement. PDF, Excel or CSV. The file is read on this phone and isn't uploaded anywhere.

          How to get your ICICI statement
          1. ICICI net banking (website): log in → Bank Accounts → Account Statement. Choose the date range (e.g. 01/08/2026 to today) and download as PDF or XLS.
          2. iMobile app: open your account → Statement → pick the period → download or email it to yourself.
          3. If it arrives by email, open the attachment and tap Share → Save to Files.
          4. Here, tap 🏦 Import bank statement and choose the file. If it's password-protected, Spendly will ask for the password.

          Menu names can differ slightly between app versions. Payments already in Spendly (from SMS or added by hand) are shown unticked so nothing is counted twice.

          Bank SMS

          Spendly reads the amount, payee and date on your phone. SMS text isn't saved or sent anywhere.

          iPhone: collect bank SMS automatically (recommended)

          Set this up once. Every bank SMS is then added to a file in iCloud Drive, and you import them all with 📥 Import SMS inbox whenever you like.

          1. Open the Shortcuts app → Automation tab → + (or New Automation) → Message.
          2. Tap Message Contains and type debited. Choose Run Immediately, then tap Next → New Blank Automation.
          3. Add the action Text. In its box:
            • tap Shortcut Input above the keyboard (if it offers choices, pick Content),
            • start a new line and type Received: then tap Current Date,
            • start a new line and type --- (three dashes).
          4. Add the action Append to Text File. Set the file to Spendly inbox.txt and turn on Make New Line. Tap Done.
          5. Repeat steps 1–4 for other words your bank uses, such as spent and Sent Rs. Messages caught twice are only imported once.

          To import: tap 📥 Import SMS inbox → Browse → iCloud Drive → Shortcuts → Spendly inbox.txt. You never need to empty the file: messages already imported are skipped.

          Just one SMS?

          In Messages, tap and hold the SMS → Copy, then tap 📋 Paste SMS in Spendly.
